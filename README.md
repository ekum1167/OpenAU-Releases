# OpenAU Downloads

Official macOS downloads for OpenAU.

OpenAU is a lightweight menu bar host for running an Audio Unit plug-in chain on the current Mac output. The source code is maintained in a private repository; this public repository contains release binaries and checksums only.

## Install

1. Open the latest release.
2. Download `OpenAU-<version>.dmg`.
3. Open the disk image and drag OpenAU to Applications.
4. Launch OpenAU and approve System Audio Recording once when macOS asks.

A signed and notarized release will appear on the Releases page when the first public build is ready.
